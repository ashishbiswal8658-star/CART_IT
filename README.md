## 📝 About CART_IT

**CART_IT** is an ultra-premium luxury e-commerce platform delivering high-end tech, audio equipment, living décor, and active wearables. Features include advanced product browsing, intelligent cart management, seamless checkout, real-time order tracking, AI-powered concierge chatbot, dark/light themes, seller dashboard, and comprehensive product reviews. Built with vanilla JavaScript for fast performance.

---

## ✨ Key Features

- 🏪 **Premium Product Catalog** - Tech, Audio, Living Decor, Wearables
- 🔍 **Live Search & Autocomplete** - Intelligent product discovery
- 🛒 **Smart Shopping Cart** - Real-time cart management with quantity controls
- 💳 **Multi-Step Checkout** - 3D credit card visualization, shipping details
- 📦 **Order Tracking** - Real-time shipment timeline with progress animation
- 💬 **AI Concierge Chat** - Smart customer support bot
- 🌓 **Dark/Light Theme** - Seamless theme switching
- ⭐ **Rating & Reviews** - Customer feedback system
- 🎫 **Promo Codes** - Coupon validation (CARTIT20, WELCOME50, FREESHIP)
- 👨‍💼 **Seller Admin Panel** - Manage inventory and add products
- 📱 **Responsive Design** - Works on all devices

## 🚀 Getting Started

### Prerequisites
- Node.js (v14 or higher)
- npm

### Installation

```bash
# Clone the repository
git clone https://github.com/yourusername/CART_IT.git
cd CART_IT

# Install dependencies
npm install

# Start the development server
npm start
```

The application will be available at `http://localhost:3000`

## 🔧 Customization

### Update Products
Edit `products.js` to modify product catalog, prices, and details.

### Modify Styles
Update `style.css` with CSS variables in `:root` for instant theme changes.

### Add Coupons
Update `VALID_COUPONS` object in `app.js` to add new promo codes.
